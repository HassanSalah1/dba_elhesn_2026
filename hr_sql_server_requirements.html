المتطلبات الفنية وقواعد البيانات من طرف SQL Server — (المرحلة الثالثة: HR Module)

1. شاشات الحضور والانصراف (Attendance & Work Schedule)
📱 الشاشات في التطبيق: شاشة حضور وانصراف الموظفين (مع الفلترة بالقسم والموظف) + شاشة سجل الحضور والتقويم الشهري والنسبة المئوية.

فئات الموظفين والأقسام (Employee Categories)

VIEW MobileApp_HR_EmployeeCategories
اسم الحقل (SQL) نوع البيانات ملاحظة المفتاح الوصف والشرح
CategoryID int PK المعرف الفريد للفئة / القسم (مثال: إدارة رياضية، أجهزة فنية...).
CategoryNameAR nvarchar(150) — اسم الفئة بالعربية.
CategoryNameEN nvarchar(150) — اسم الفئة بالإنجليزية.
Active bit — حالة الفئة (1 = مفعل، 0 = غير مفعل).

بيانات موظفي النظام (HR Employees)

VIEW MobileApp_HR_Employees
اسم الحقل (SQL) نوع البيانات ملاحظة المفتاح الوصف والشرح
EmployeeRowID int PK المعرف الفريد للموظف في نظام HR.
UserID int FK رقم الحساب المرتبط بالموظف في جدول MobileApp_Users.
CategoryID int FK معرف القسم التابع له الموظف.
NameAR nvarchar(150) — اسم الموظف بالعربية.
NameEN nvarchar(150) — اسم الموظف بالإنجليزية.
JobTitle nvarchar(150) — المسمى الوظيفي (اختياري).
Photo nvarchar(500) — رابط أو مسار صورة الموظف.

سجلات الحضور والانصراف اليومية (Attendance Records)

VIEW MobileApp_HR_AttendanceRecords
اسم الحقل (SQL) نوع البيانات ملاحظة المفتاح الوصف والشرح
RowID bigint PK معرف سجل الحضور.
EmployeeRowID int FK معرف الموظف صاحب السجل.
AttendanceDate date — تاريخ اليوم (مثال: 2026-03-18).
CheckInTime time / datetime — وقت الحضور والتوقيع.
CheckOutTime time / datetime — وقت الانصراف.
Status varchar / tinyint — حالة اليوم (1 = حاضر ✓ أخضر ، 2 = غائب ✗ أحمر ، 3 = إجازة/إذن برتقالي).
Notes nvarchar(250) — ملاحظات أو سبب التأخير/الغياب.
2. شاشات الإجازات والتقارير الإدارية (Leave Requests & Reports)
📱 الشاشات في التطبيق: إضافة طلب إجازة (اختيار النوع، التواريخ، وصف داعم، مرفقات) + أرشيف طلبات الإجازة وتفاصيل التقرير.

أنواع الإجازات المتاحة (Leave Types)

VIEW MobileApp_HR_LeaveTypes
اسم الحقل (SQL) نوع البيانات ملاحظة المفتاح الوصف والشرح
TypeID int PK معرف نوع الإجازة (مرضي، سنوي، طارئ، دراسية، بدون راتب، أمومة، حج...).
TypeNameAR nvarchar(150) — اسم الإجازة بالعربية.
TypeNameEN nvarchar(150) — اسم الإجازة بالإنجليزية.
Active bit — حالة التفعيل (1 = مفعل).

جدول استقبال وأرشيف الإجازات (Leave Requests Sync Table)

TABLE MobileApp_HR_LeaveRequests
اسم الحقل (SQL) نوع البيانات ملاحظة المفتاح الوصف والشرح
RequestID bigint PK معرف الطلب القادم من التطبيق.
EmployeeRowID int FK معرف الموظف صاحب الطلب.
TypeID int FK معرف نوع الإجازة.
StartDate date — تاريخ بداية الإجازة.
EndDate date — تاريخ نهاية الإجازة.
Description nvarchar(max) — حقل "وصف داعم" / تفاصيل وسبب الإجازة.
AttachmentUrl nvarchar(500) — رابط المرفق الداعم المرفوع.
Status varchar / tinyint — حالة الطلب في الأرشيف (0 = قيد المراجعة، 1 = مقبول، 2 = مرفوض).
CreatedAt datetime — تاريخ ووقت إضافة الطلب.
AdminReplyNotes nvarchar(500) — ملاحظات أو تعليق المسؤول عند القبول/الرفض.
3. شاشات أرشيف المستندات الإدارية (Administrative Documents)
📱 الشاشات في التطبيق: أرشيف المستندات (تقارير الأداء، عقود، محاضر جلسات...) + إضافة مستند وتفاصيل المستند.

جدول مستندات وتقارير الموظفين (Employee HR Documents)

TABLE MobileApp_HR_Documents
اسم الحقل (SQL) نوع البيانات ملاحظة المفتاح الوصف والشرح
DocumentID bigint PK المعرف الفريد للمستند.
EmployeeRowID int FK معرف الموظف المعني بالمستند.
Description nvarchar(max) — عنوان / "وصف المستند" (مثل: تقرير الأداء السنوي، خطة التسويق...).
AttachmentUrl nvarchar(500) — رابط أو مسار الملف المرفوع قابل للتحميل والتصفح.
CreatedAt datetime — تاريخ رفع أو إضافة المستند.

💡 آلية المزامنة البرمجية (Integration Workflow):

  • طريقة نقل الطلبات والمستندات (Push Sync): عند قيام الموظف بإضافة طلب إجازة جديد أو رفع مستند، يتم عمل INSERT مباشر في جدولي MobileApp_HR_LeaveRequests و MobileApp_HR_Documents في قاعدة البيانات SQL Server.
  • القراءة والمتابعة (Pull Sync): يقرأ التطبيق بيانات الحضور والغياب وأنواع الإجازات وأرشيف المستندات لعرضها بشكل فوريللمستخدم في شاشات الموبايل والويب.
